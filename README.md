# Product Leadership - Final Project

Working repo for the Product School "Product Leadership" certification final project. Each module's lab guide specifies a deliverable folder; commits land there as each module is completed.

## Case study

Scenario: Meridian (B2B construction, "The Field Gap"). Per the program's own rules, this is chosen once and carried through all six modules with no switching.

## Structure

**01-strategy/** - Module 1: Playing to Win cascade, hard no, and OKR cascade, plus notes from the AI pressure-test exercise.

**02-roadmap/** - Module 2: backlog audit (Rocks and Hard Nos, peer review) and the Now/Next/Later roadmap with its review notes.

**03.../ through 06.../** - added as each module's lab guide specifies its own deliverable folder name.

## Note

This repo holds certification coursework built on an assigned case study, not Aiven Consulting Group's own product strategy. Aiven's real strategy lives in the separate AI-Product-Strategy---Orchestrator repo.
